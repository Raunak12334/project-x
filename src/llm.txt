# Otogent

> Otogent is an agentic automation platform for building and running multi-agent AI workflows at production scale. It provides a visual workflow builder, DAG-based parallel agent execution, per-agent token management, and multi-model LLM support (OpenAI, Anthropic Claude, Google Gemini).

## What Otogent does
- Orchestrates fleets of AI agents across asynchronous, parallel execution graphs
- Manages workflow state, token budgets, and human-in-the-loop approval gates
- Supports triggers from HTTP, webhooks, Slack, Discord, Google Forms, and more
- Encrypts and manages LLM credentials with AES encryption
- Provides pre-built blueprints for Real Estate, Healthcare, E-commerce, Finance, Marketing, and Education

## Who it's for
- Engineering teams shipping production AI workflows
- Businesses automating complex multi-step processes with LLMs
- Non-technical users who need no-code agent automation
