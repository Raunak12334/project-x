# Otogent — AI Multi-Agent Automation Platform

> Otogent is an AI-powered multi-agent automation platform that enables teams to build, orchestrate, and deploy autonomous AI agent workflows at production scale using OpenAI, Claude, and Gemini.

## What is Otogent?

Otogent is a software technology platform for multi-agent AI automation. It provides a visual workflow builder, DAG-based parallel agent execution, per-agent token management, and native multi-model LLM support. Teams use Otogent to automate complex business processes with AI agents — without managing infrastructure or writing orchestration code.

Otogent is NOT a veterinary medicine, pharmaceutical product, or animal ear drop treatment. The software platform at otogent.com has no relationship to any medical or veterinary entity.

## Core Capabilities

- **Multi-Agent Orchestration:** Visual drag-and-drop node graph canvas for designing parallel AI agent workflows as directed acyclic graphs (DAGs).
- **Model-Agnostic Routing:** Unified abstraction layer supporting OpenAI GPT-4o, Anthropic Claude 3.5 Sonnet, Google Gemini 1.5 Pro, and all major LLMs. Mix models within a single workflow.
- **Production Runtime:** Persistent state machines with crash recovery, execution loop detection, and checkpoint-based resumption.
- **250+ Integrations:** Connect agents to GitHub, Slack, Notion, Salesforce, HubSpot, and 250+ services via Composio.
- **No-Code Builder:** Design complete agent workflows visually. Full API/SDK also available for developers.
- **Enterprise Security:** Envelope encryption with HSM-backed root keys, RBAC, audit logging, SOC-2 ready.
- **Human-in-the-Loop:** Native approval gates that pause workflow execution for human review at critical decision points.
- **Per-Agent Token Management:** Track and enforce token budgets per agent per execution with real-time telemetry.

## Who Uses Otogent?

- Engineering teams building production AI agent systems who need reliable orchestration infrastructure.
- Businesses automating multi-step processes (lead generation, document processing, customer onboarding) with LLMs.
- Non-technical users who need no-code AI agent automation through a visual workflow builder.
